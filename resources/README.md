# Resources

This directory contains information on the reference genome assemblies used in the transcriptome reconstruction workflows.

## Reference genomes

Genome assemblies used for BBSplit classification and genome-guided transcriptome reconstruction are listed in:

`reference_genomes.md`

The reference datasets include:

- Four *Arachis hypogaea* genome assemblies used for host-pathogen read classification.
- The draft *Thecaphora frezzii* genome assembly used for read classification and residual fungal-sequence filtering.
- The diploid peanut progenitors *Arachis duranensis* and *Arachis ipaensis* used to construct the combined reference for genome-guided transcriptome reconstruction.
