# Reference genomes

Reference genome assemblies used in the transcriptome reconstruction workflows.

## Read-classification-based reconstruction

Preprocessed RNA-seq reads were classified using BBSplit against four *Arachis hypogaea* genome assemblies and the draft *Thecaphora frezzii* genome assembly.

## Genome-guided reconstruction

A combined diploid-progenitor reference was generated by concatenating the genome assemblies of *Arachis duranensis* and *Arachis ipaensis*, representing the A and B subgenomes of cultivated peanut, respectively.

| Species | Genome assembly | Accession |
|---|---|---|
| *Arachis duranensis* | aradu.V14167.gnm2.J7QH | GCA_000817695.3 |
| *Arachis ipaensis* | Araip1.1 | GCA_000816755.2 |
