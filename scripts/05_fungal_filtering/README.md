# Removal of residual fungal sequences

This directory documents the removal of residual *Thecaphora frezzii*-derived sequences from the curated peanut transcriptomes.

The filtering procedure was applied to transcriptomes generated by both reconstruction strategies after EvidentialGene curation.

## Alignment against the fungal reference genome

EvidentialGene-curated transcriptomes were aligned against the *Thecaphora frezzii* draft genome assembly ASM2628400v1 (GCA_026284005.1) using Subread v2.0.6.

The fungal reference genome is listed in:

`../../resources/reference_genomes.md`

## Transcript filtering

Transcript identifiers corresponding to sequences mapping to the *T. frezzii* genome were extracted from the resulting SAM files.

Custom Python scripts were subsequently used to remove these potentially fungal-derived sequences from the EvidentialGene-curated FASTA files.

The resulting transcript sets were considered the final peanut transcriptomes for subsequent quality assessment and coding-sequence prediction.
