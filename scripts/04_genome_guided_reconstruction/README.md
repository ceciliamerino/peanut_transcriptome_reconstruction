# Genome-guided transcriptome reconstruction

This directory documents the genome-guided transcriptome reconstruction workflow used for *Arachis hypogaea*.

The workflow was applied independently to each genotype.

## Read normalization

Preprocessed paired-end reads from each sample were normalized using Trinity v2.15.2.

Parameters:

- Paired reads maintained together: `--pairs_together`
- Maximum coverage: `--max_cov 50`
- Strand-specific library orientation: `--SS_lib_type FR`

## Combined diploid-progenitor reference

A combined reference genome was generated by concatenating the genome assemblies of the two diploid progenitors of cultivated peanut:

- *Arachis duranensis* aradu.V14167.gnm2.J7QH — GCA_000817695.3
- *Arachis ipaensis* Araip1.1 — GCA_000816755.2

Reference genome details are provided in:

`../../resources/README.md`

## Read alignment

Normalized reads were aligned to the combined diploid-progenitor reference using GSNAP v2017-01-14.

## BAM processing

Alignment files were converted to coordinate-sorted BAM files using SAMtools.

BAM files corresponding to individual samples were subsequently merged by cultivar.

## Genome-guided assembly

Merged BAM files were used as input for genome-guided transcriptome reconstruction with Trinity v2.15.2.

The original analysis used Trinity through a Singularity container with the following parameters:

- `--genome_guided_bam`
- `--max_memory 40G`
- `--CPU 5`
- `--no_normalize_reads`
- `--genome_guided_max_intron 15000`

The corresponding script is:

`trinity_genome_guided.sh`

The resulting genome-guided transcriptomes were subsequently curated using EvidentialGene.

## Scripts

- `Snakefile` — performs Trinity in silico read normalization, alignment of normalized reads to the combined diploid-progenitor reference using GSNAP, and conversion of alignment files to coordinate-sorted BAM format.
- `merge_bams_by_cultivar.sh` — merges and sorts sample-level BAM files by cultivar.
- `trinity_genome_guided.sh` — reconstructs genome-guided transcriptomes from cultivar-level merged BAM files using Trinity.
- `evidentialgene_curation.sh` — curates the genome-guided Trinity transcriptomes using EvidentialGene.
