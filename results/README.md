# Results

This directory contains summary results generated during the comparative evaluation of peanut transcriptome reconstruction strategies.

Two transcriptome reconstruction approaches were evaluated independently for three *Arachis hypogaea* cultivars (Granoleico, FAVar-2, and Ascasubi):

1. Read-classification-based de novo reconstruction
2. Genome-guided reconstruction

## Transcriptome assembly and completeness

Transcriptome quality was evaluated using assembly statistics and BUSCO completeness.

Summary metrics include:

- Number of transcripts
- Total assembled length
- N50
- Complete single-copy BUSCOs
- Complete duplicated BUSCOs
- Fragmented BUSCOs
- Missing BUSCOs

Final transcriptomes generated by both reconstruction strategies showed high overall gene completeness.

Genome-guided transcriptomes contained a larger number of transcripts across all cultivars but did not show systematic improvements in overall BUSCO completeness.

## Protein-length analysis

Predicted protein sequences were deduplicated prior to protein-length analysis.

Summary statistics include:

- Number of unique predicted protein sequences
- Median protein length
- 99th percentile (P99)
- Maximum protein length

Protein-length distributions were broadly comparable between reconstruction strategies.

## Protein homology assessment

DIAMOND BLASTp results were evaluated using:

- Alignment length
- Bit score
- Percentage identity

These analyses were used to characterize sequence-similarity support for predicted proteins.

## Data availability

Curated transcriptome assemblies and associated datasets have been deposited in Zenodo.

Raw RNA-seq reads are deposited in the NCBI Sequence Read Archive (SRA).
